## If you only have two minutes

Open The Machine, hit **Verify the math**, and let him look up "AA vs KK equity"
on his phone while it counts through 1,712,304 boards. It lands on 81.9461%.

## Running offline

Every app is one self-contained HTML file — double-click it. No server, no
install, no network. Add `#test` to any URL to run its in-page test suite
(37 for The Machine, 35 for Coast Clash).
